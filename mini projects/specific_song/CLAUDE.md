# specific_song — CLAUDE.md

## What this project does

On-demand song player. Activated by typing `i → l → i` within a time window.
Opens the mic, transcribes the spoken song name, fuzzy-matches it against a
library, and plays the matching OBS media source in the `SpecificSongs` scene.
Supports random/shuffle mode, manual direct-play hotkeys, and pause/resume.

## Scene ownership

**Owns:** `SpecificSongs`

All OBS interaction (show/hide source, restart media) stays inside this scene.

## Key files

| File | Role |
|---|---|
| `main.py` | Hub entry point — keyboard listener, voice flow, random mode |
| `player.py` | `SongPlayer` — wraps `obs.show_source` / `obs.restart_media` / pause/resume |
| `matcher.py` | Fuzzy song matching (`find_best_match`, `rank_matches`) |
| `trigger.py` | `SequenceTrigger` for the `ili` hotkey sequence |
| `config.py` | Song JSON path, trigger sequence, match threshold, manual hotkeys |
| `interface.py` | `ProjectInterface` — `pause()` / `resume()` / `revert()` delegate to `SongPlayer` |
| `full_sync.py` | Standalone script to scan the songs folder and generate `songs.json` |

## Song library

Songs are stored as OBS media sources in the `SpecificSongs` scene.
The library metadata lives in `songs.json` (generated by `full_sync.py`).
Each entry has `"name"` (display/match name), `"source"` (OBS source stem),
and optional `"aliases"` (extra match strings).

To add songs:
1. Add the media source to OBS in the `SpecificSongs` scene.
2. Run `python "mini projects/specific_song/full_sync.py" --apply` to update `songs.json`.

## Hotkey flow

```
Type i → l → i  (within TRIGGER_MAX_INTERVAL)
    └─ If already recording  →  stop + send immediately
    └─ If in MANUAL_TRIGGER_WINDOW  →  check for direct-play key
    └─ Otherwise  →  wait MANUAL_TRIGGER_WINDOW, then open mic
         └─ Speak song name  (auto-sends after 2 s, or press 'C')
              └─ Transcription → fuzzy match → play
```

While a song plays:
- `ili` pauses the song and opens the mic simultaneously.
- If a new song is matched: old song is aborted, new song plays.
- If no match: old song resumes.

## Manual direct-play hotkeys

After `ili`, pressing a configured key within `MANUAL_TRIGGER_WINDOW` seconds
plays a song instantly without voice. Configured in `config.py → MANUAL_TRIGGER_SONGS`:
```python
MANUAL_TRIGGER_SONGS = {
    "1": "song_stem_here",  # ili+1 plays this source
    "2": "",                # unassigned
}
```

## Voice commands

After `ili` + mic opens, say:
- `"random"` / `"shuffle"` — start shuffle mode (cycles all songs, no repeats until all played)
- `"next"` / `"skip"` — skip to next (shuffle mode only)
- `"stop"` / `"abort"` — stop playback + exit random mode
- `"reload"` — reload `songs.json` without restarting

## Pause/resume integration

`interface.py` implements `pause()` and `resume()` by delegating to `SongPlayer`.
When another project calls `project_registry.pause_all()`, this project pauses at
the current playback position. `resume_all()` resumes from where it left off.

## `_live` dict (interface ↔ main)

`main.py` populates these after object creation:
- `_live["player"]` — `SongPlayer` instance
- `_live["rand_active"]` — `list[bool]`, True while random loop runs
- `_live["stop_random"]` — callable that exits the random loop
