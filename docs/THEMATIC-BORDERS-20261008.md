# Thematic border performances

Requested keys: `Z T t 1 ! 2 @ 3 # 4 $ %`, case-sensitive. This expands to 40
distinct sounds in the personal `default` profile. `4` has no binding; no asset
or example binding is assigned. OBS must not be opened for this work.

The target is the approved Muffin/Speed balance: a visible peripheral performance,
recognizable characters and props, small visual jokes with consequences, smooth
movement and a transparent gameplay opening. All artwork uses the existing audio
or director clock. No original sound, duration, hotkey, gain, profile, OBS filter,
transform, placement rule, recording path or event preference is changed.

## League events

Every non-Hextech built-in event has a new flat illustrated performance; the
approved Hextech renderer is retained exactly. This includes disabled optional
events and inferred signals, without enabling any of them.

Structures grow into crooked tower/crystal shapes before crushing into settled
rubble. First turret adds reward coins; inhibitor return reverses fragmentation
into assembly. Respawn places turtle, phoenix, ram and bear in four fixed border
sections: each wakes and rises, with its own shell, wings, horns or paws. Death
rests the same four spirits. Dragon habitats use rock growth, campfire curls,
rain/water/duck, cloud/paper-plane drift, flask fizz or sleepy elder wisps, with
quiet versions for the existing sustained ambience clock.

Combat uses sword/target, high-five, clutch heart and counted reward-star actions.
Objectives use the horned Baron, one-eyed hopping Herald, springy grubs and a
masked objective thief whose reward travels around the perimeter into its hand.
Upgrades use steps, a hinged lock and spirit unlocks. Economy
uses a backpack/item slot, wheat harvest and a ward that sees through fog.
Match start opens gates, minions march in lanes, victory raises a smiling cup,
defeat turns the page and grows a new sprout, and game end closes the storybook.
Tentative signals retain question marks instead of claiming confirmed events.

## Ownership and verification

Feature-local drawing owners are assembled by `tools/build_border_art.py` into
the existing static routes. No new transport, worker, scene writer, timer,
decoder, hook or playback source is introduced. Personal strength and enabled
state remain owned by the existing production director/settings.

`tools/review_thematic_borders.cjs` is a finite, intercepted-route Chromium review
with no live Hub or OBS. It checks all selected sounds and League entries at nine
moments, exact audio duration/end cleanup, backward seeking, distinct League
composition, center transparency, coverage/glare limits, structure growth before
collapse, settled rubble, four spirits waking/rising, ambient motion and exact
Hextech pixels. Art and original-audio previews live in `output/thematic-borders/`.

Open thematic rim currents and traveling props support the main acts without
filled scenic panels. Finite structural fragments grow and crush along every
edge; spirit traces, elemental currents and event-specific particles use the
same elapsed clock as their characters.

`py -3.11 tools/build_thematic_preview.py` packages the actual renderer modules
as a standalone local `output/thematic-borders/preview.html`. It offers original
audio, play/pause, seek, backdrop choices and all optional League entries. It
reads local media only and sends no Hub, OBS or keyboard commands.
`tools/test_thematic_preview.cjs` verifies the delivered controls and file-only
requests. No application restart is required for the static artwork; the Hub
was not running when this work began and remains stopped.

The follow-up individual audit adds cue-specific edge signatures, single
particle-birth windows, causal second-act entrances and held endings. Five
counted combat cues now have five different compositions: twin pennants, a
three-blade fan, a four-petal compass, a small Pentakill concert and an ace
clean sweep. Dragons have distinct element-specific anatomy. Contact fixes cover
rose grip, Cupid impact, returned hat, fish gulp, podium/stair landings and item
slots. `tools/test_border_choreography.cjs` checks these geometric contracts;
`tools/build_border_audit.py` publishes all 99 individual decisions after the
original-audio review passes.

For a later League-only drawing correction, the finite review tool can use
`--reuse-sound-playback`. It accepts the saved original-audio proof only when
the sound renderer bytes, original media hashes and personal sound data match,
and all nine freshly rendered sound frames are exactly identical. It still
decodes original duration and rechecks sound cutoff/seek/center/cleanup and every
League frame. A changed sound requires a fresh original-audio run. Repeated
pixel captures request a consistent CPU canvas readback backend, avoiding tiny
GPU antialiasing-cache differences without relaxing exact rewind equality.
