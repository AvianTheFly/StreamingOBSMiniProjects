# Live desk

The desk follows the scene on OBS. **Change stage** opens another set of controls;
browsing does not change the stream. The main desk has no picture preview.

| Section | Controls |
| --- | --- |
| Starting soon | Choose image, Use image, Next image, Auto-change, Play intro, Go to lobby. |
| Opening | Skip to lobby. Sanctuary plays once for 40 seconds, then enters a lobby. |
| Lobby | Current lobby, Next lobby, Switch lobby, Browse, New each visit / Keep this lobby, effects, desktop visibility. |
| Queue / champ select | Show champ select, Show queue lobby, Go to game. |
| Game | Replay last 15s, Replay latest, Return to live, Sounds, Music. |
| Ending | Choose and show the ending lobby. |

**New each visit** picks from your saved rotation and avoids the current world
when another is available. **Keep this lobby** saves one world for future
automatic entries. Both preserve your rotation membership, layouts and filters.
Gallery choices are drafts until **Use image**, **Show starting screen** or
**Switch lobby**. The current-lobby label always describes the observed world.
**Next lobby** changes this visit without replacing the saved rotation preference.
Effects target only the lobby currently on screen.

**Auto scenes / Hold view** allows or holds automatic scene changes.
Show ending holds its view; Show lobby or Show game releases the hold.
**Go live / End stream** starts or stops broadcasting separately from scene choice.

Loading is a League phase within Game. Replay capture needs the OBS replay buffer;
**Enable replays** appears when it is off. **Return to live** appears during replay.
A newer manual scene choice cancels the intro's automatic lobby return.

**Other scenes** contains installed welcome, intermission, signoff, desktop,
away and court scenes. When one is on screen, it gets a small panel with
Go to lobby / Go to game. Audio, playlists, saved clips, alerts and workflows stay
under collapsed controls. Browsing remains available when OBS is closed;
live commands require its connection.
