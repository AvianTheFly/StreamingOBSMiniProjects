# Built-in image-generation prompts

Generated with the built-in image-generation tool. Every prompt requested an original animal-spirit character, a transparent 4-by-2 acting-pose sheet, no logos, no existing characters, no written text, no grid lines and no watermark. Captions were added during GIF compositing.

- **OHNOO** — jade turtle spirit: confident glance → notice → eyes wide → hands on head → cyan psychic overload → flailing back → shell-first flop → dazed recovery. Mood: chaotic funny panic; cyan and jade effects.
- **COPIUM** — thunder ram spirit: smug posture → notice loss → pulls a glowing blue potion → stares → shakes → huge reluctant drink → watery-eyed recovery. Mood: over-the-top denial.
- **YEP** — blazing phoenix spirit: cool stance → two nods → sunglasses down → points at viewer → thumbs-up → finger guns → wings-out pride. Mood: confident, flashy approval.
- **BONK** — bear spirit brawler: strut → spot a foam mallet → confusion → incoming swing → face squash → spinning eyes → sore head → sheepish shrug. Mood: colorful slapstick.
- **SLEEPY** — jade turtle spirit: alert → slow blink → yawn → wobble → conjures star pillow → curls into shell → dream sparks → startled wake. Mood: whimsical queue nap.
- **HYPE** — thunder ram spirit: crouch → electricity charge → two neon glowsticks → raise → swing left → swing right → lightning leap → victory landing. Mood: rave-like party energy.
